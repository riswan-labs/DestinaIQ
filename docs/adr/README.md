# Architecture decision records

Record significant changes before implementing them. Use a numbered file with status, decision owner/date, context, alternatives, decision, rationale, consequences and related requirements or checkpoints. Record supersession explicitly. Approval comes from the project owner or a delegated decision owner. Existing design commitments are summarized in [architecture](../architecture/ARCHITECTURE.md). Open choices are tracked in the [decision register](../governance/DECISION_REGISTER.md).
