# Checkpoint template

- Phase and checkpoint
- Project-owner authorization
- Status (Not Started, In Progress, Under Review, Accepted or Blocked)
- Scope and upstream dependencies
- Deliverables
- Linked capability, FR, NFR and ADR IDs
- Measurable acceptance criteria
- Verification commands, outcomes and evidence links
- Exit gate and approval
- Risks, blockers, assumptions and unresolved decisions
- Feature branch and draft PR
- Next authorized action

Record implementation evidence separately from documentation. Only the project owner can accept a checkpoint.
