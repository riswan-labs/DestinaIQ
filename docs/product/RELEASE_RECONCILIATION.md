# Design V3 release reconciliation

The Design V3 §21 release stays authoritative for every FR. Customer availability follows the release gate, including when an early foundation or a later-phase slice supports it. “Source boundary” records a documented source constraint. “Approved scheduling (D21)” records approval of seven release slices. Cross-phase work requires explicit task-level authorization, verified dependencies and bounded pull request scope. “Open scope” records deferred V3.0 requirements under D17.
