The capability matrix uses the six classifications from the assignment. Verified supported refers only to the tested slice; partially supported identifies a directly observed subset; advertised but unverified includes official declared capabilities; unknown or inaccessible indicates insufficient evidence. Verified unsupported requires affirmative evidence of the specific limitation. DestinaIQ entries are planned and reference stable FRs; no product code was evaluated. Evidence IDs resolve in the register. TSV cells contain plain text suitable for independent review.
