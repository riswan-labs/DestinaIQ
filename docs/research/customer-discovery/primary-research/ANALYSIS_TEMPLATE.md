# Primary evidence analysis template

Blank template. Keep working data in a private approved store. The public repository may receive aggregated findings only with owner authorization.

| Field | What to enter after authorization |
| --- | --- |
| Study / channel / period | Research version, recruitment source and elapsed fieldwork |
| Coded participant and consent | Private study code and consent state; suppress personal details |
| Segment and journey | Broad trip type and stage, with missing values retained |
| Past behavior and alternatives | Actual tools, time bands, purchase/cancellation and observed workarounds |
| Claim, counterexample and confidence | Theme IDs, independent corroboration, negative evidence |
| Mock concept outcome | Task completion and source tracing, then intent/preferences separately |
| Price format and denominator | Randomization order, prior purchase, rejected answers and no-interest |
| Follow-up / decision gate | FR/NFR/launch mapping, owner and still-needed data |

Aggregate by recruitment channel and segment only when cell count permits. Review coding with a second reviewer, record disagreements, and separate pilots from changed instruments. No individual excerpts or raw responses in the repo. Report actual denominators and avoid implying representativeness. Capture decision impact, uncertainty, and whether evidence supports a pilot, more discovery, or stopping.
