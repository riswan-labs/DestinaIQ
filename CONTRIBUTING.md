# Contributing

Confirm the approved checkpoint in [progress](docs/engineering/PROGRESS.md). Work on a dedicated branch and open a draft PR with requirement IDs, evidence, decisions and outstanding gates. Use the [checkpoint template](docs/engineering/CHECKPOINT_TEMPLATE.md) and [engineering standards](docs/engineering/ENGINEERING_STANDARDS.md). Keep scope focused and link significant decisions to an [ADR](docs/adr/README.md).

The project owner controls review readiness, checkpoint acceptance, merge and subsequent checkpoint approval. Changes to the design baseline require an owner-reviewed revision and corresponding traceability updates.
